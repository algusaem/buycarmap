# Chip

Filtros rápidos en una fila bajo el buscador; el activo se rellena de `violet` y sube a peso 800, el resto es un borde `line`.

- Es un botón con `aria-pressed`: el estado no va solo en el color, también cambia el relleno y el peso.
- Texto corto, en el idioma del comprador: «Diésel», «Automático», «Menos de 100.000 km», «Últimas 24 h».
- El chip «Filtros» abre el panel completo y lleva el número de filtros activos en una insignia `violet`.
- En móvil la fila se desliza en horizontal; no se parte en dos líneas.
